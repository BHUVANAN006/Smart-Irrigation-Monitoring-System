How the percentage works

Initial project thresholds for a calibrated soil-moisture sensor.

0–29%Very dry
30–44%Low moisture
45–64%Moderate moisture
65–79%High moisture
80–100%Very wet

Important: These percentages are normalized sensor values, not laboratory volumetric water content. Calibrate the dry and wet ADC values in the ESP32 code before field use.
